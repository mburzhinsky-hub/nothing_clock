# Glyph Ambient

Минималистичный ambient display для iPhone и браузера.

## Режимы

Вертикальный свайп переключает:

- **Clock** — часы
- **Date** — дата и день недели
- **Weather** — локальная температура и погода
- **Timer** — таймер с регулируемой длительностью
- **Focus** — 25-минутный focus mode с точечным прогрессом
- **Dream** — генеративный screensaver: частицы морфят в текущее время или переходят в constellation field

## Глифы

Горизонтальный свайп переключает пять систем:

- **Dot Matrix**
- **Segment**
- **Hybrid**
- **Wire**
- **Stencil**

## Управление

- **Свайп влево/вправо** — сменить стиль глифов
- **Свайп вверх/вниз** — сменить режим
- **Тап** — показать/скрыть панель управления
- **Weather → Locate** — запросить геолокацию и загрузить текущую погоду через Open-Meteo; после загрузки погода становится ambient-фоном
- **Dream** — MORPH собирает частицы в текущее время, FIELD превращает их в генеративное поле
- **Timer** — ±1 минута, Start/Pause, Reset
- **Focus** — Focus/Pause, Reset
- правая вертикальная колонка точек — быстрый выбор режима

Тема, стиль, режим и длительность таймера сохраняются на устройстве.

## Motion

- Dot / Hybrid используют morph-переход: меняющиеся элементы перелетают к новой форме цифры.
- Wire использует бегущий штрих по контуру.
- Weather анимирован и внутри самого weather glyph, и фоновыми rain / snow / cloud / orbit-эффектами.
- Dream работает как отдельный генеративный screensaver.

## PWA

- standalone
- landscape preference
- offline-кэш интерфейса
- Screen Wake Lock, если поддерживается браузером
