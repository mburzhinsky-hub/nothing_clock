# Glyph Clock

Минималистичные полноэкранные часы для iPhone и браузера.

## Что есть

- три системы глифов: **Dot Matrix**, **Segment**, **Hybrid**
- темная и светлая темы
- выбор стиля сохраняется на устройстве
- свайп влево/вправо переключает стиль
- тап по экрану показывает компактные настройки
- PWA / standalone
- офлайн-кэш
- предпочтительная ориентация — landscape
- Screen Wake Lock, если браузер поддерживает API

## Управление

- **Тап по экрану** — показать/скрыть панель
- **Свайп влево/вправо** — сменить глифы
- кнопка справа — Dark / Light

В обычном состоянии на экране остается только время.

Откройте сайт в Safari → Share → **Add to Home Screen**, затем запускайте с домашнего экрана и поверните iPhone горизонтально.
