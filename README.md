# Glyph Clock

Минималистичные полноэкранные часы для iPhone и браузера.

## Что есть

- пять систем глифов: **Dot Matrix**, **Segment**, **Hybrid**, **Wire**, **Stencil**
- темная и светлая темы
- ненавязчивые переходы при смене минут и стиля
- слабый постоянный ghost-каркас для Dot / Segment / Hybrid / Stencil
- выбор стиля и темы сохраняется на устройстве
- свайп влево/вправо переключает стиль
- тап по экрану показывает компактные настройки
- PWA / standalone
- офлайн-кэш
- предпочтительная ориентация — landscape
- Screen Wake Lock, если браузер поддерживает API

## Стили

- **Dot Matrix** — точечная матрица
- **Segment** — чистый сегментный дисплей
- **Hybrid** — смесь точек и капсул
- **Wire** — тонкий контурный режим
- **Stencil** — рубленые сегменты с вырезанными углами

## Управление

- **Тап по экрану** — показать/скрыть панель
- **Свайп влево/вправо** — сменить глифы
- кнопка справа — Dark / Light

В обычном состоянии на экране остается только время.
